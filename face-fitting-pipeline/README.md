# Face Fitting Pipeline

## Generation:
#### Requirement:
python >= 3.6\
pytorch

#### Additional Assets:
Download asset from : https://drive.google.com/file/d/1fbNA2wM37U5dfAFRDFZhy1jTRsK9zNO6/view?usp=sharing \
extract into face_generation/assets/
Note: full texture files can download at [here](https://drive.google.com/file/d/1L591BTlcJNc4i7r2bJ2coBdEv2MKyxxB/view?usp=drive_link)



#### Usage:
change gen_face.py's path = './results/000001.jpg' to your test image path.\
then run "python gen_face.py"

## Web Viewer:
#### Requirement:
Setup root folder as website. (In my case, I use VSCode's extension call "Live Server")\
A Browser

#### Usage:
Open your local server using browser.
